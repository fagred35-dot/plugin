# Roblox GitHub Sync Plugin

Плагин для Roblox Studio, позволяющий синхронизировать скрипты с репозиторием GitHub (Push, Pull, настройки, просмотр репозитория в реальном времени).

---

**Settings** — токен, репозиторий и целевая ветка:

## 🚀 Установка

1. **С использованием Rojo:**
   Убедитесь, что у вас установлен [Rojo](https://rojo.space/), затем выполните:
   ```bash
   rojo build -o GitHubSyncPlugin.rbxmx
   ```
   Импортируйте полученный `.rbxmx` файл в Roblox Studio (или откройте папку плагинов Roblox Studio и поместите туда плагин).

2. **Ручная установка:**
   Создайте папку плагина в каталоге плагинов Roblox Studio и скопируйте в неё папку `src` (переименовав её в `GitHubSyncPlugin.server.lua` или настроив `init.server.lua`).

## ⚙️ Использование

### 1. Настройка
1. В Roblox Studio нажмите на иконку настроек плагина на панели **GitHub Sync**.
2. Введите ваш **GitHub Personal Access Token (PAT)** (с правами доступа к репозиториям, например `repo` scope).
3. Введите путь к репозиторию в формате `owner/repo` (например, `username/my-roblox-game`).
4. Нажмите **Save Settings**. Данные сохраняются автоматически через `plugin:SetSetting()`.

### 2. Repository Viewer — главное окно плагина
На панели инструментов Roblox Studio осталось всего две кнопки: **Settings** и **Repo Viewer**.
Кнопки **Push** и **Pull** переехали внутрь окна Repo Viewer, чтобы действия выполнялись над той веткой, которая сейчас открыта в просмотрщике.

Внутри окна доступны:

| Кнопка | Что делает |
| --- | --- |
| **Refresh** | Перезагружает список веток и файлов текущей ветки. |
| **Branch ▼** | Выбор ветки; выбранная ветка сохраняется в настройках. |
| **Check Last Push** | Подтягивает дату последнего коммита для каждого файла. |
| **Push** | Отправляет выделенные в Studio скрипты в текущую ветку. |
| **Pull All** | Импортирует все файлы ветки в `Workspace`. |
| **Pull Selected** | Скачивает только файлы, отмеченные галочками в списке. |

### 3. Push (Отправка на GitHub)
1. Выберите в проводнике Roblox Studio нужные скрипты (`Script`, `LocalScript`, `ModuleScript`) или их родительские папки/модели (удерживая `Ctrl` для множественного выбора).
2. Нажмите **Push** в окне **Repo Viewer**.
3. Плагин создаст на GitHub папку с именем вашего места (Place) и сохранит туда выбранные скрипты с сохранением иерархии.
4. Кнопка кратко подсветится зелёным при успехе или красным при ошибке; подробности — в строке статуса и в Output.
5. После успешного Push список файлов обновляется автоматически.

### 4. Pull (Получение с GitHub)
* **Pull All:** ничего не выделяя в студии, нажмите **Pull All** — все файлы ветки импортируются как папки и скрипты в `Workspace`.
* **Pull Selected:** отметьте нужные файлы галочками в списке и нажмите **Pull Selected**.
* **Выборочно по выделению:** выделите скрипт в студии и нажмите **Pull All** — обновится только его исходный код.

*Внимание: отмена действий (`Ctrl+Z`) не работает для изменений исходного кода через плагин!*

## ⚠️ Важная деталь (Метаданные)
При отправке (Push) и получении (Pull) плагин добавляет в начало скриптов специальный комментарий с метаданными (например, `-- @ScriptType: ModuleScript`). 
**Не удаляйте этот комментарий на GitHub!** Иначе при следующем Pull плагин не сможет определить тип скрипта и импортирует его как обычный серверный скрипт (`Script`).
